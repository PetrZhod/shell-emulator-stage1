# Этап 5. Дополнительные команды

На пятом этапе реализованы команды `mkdir` и `cp`, изменяющие виртуальную файловую систему.
Все изменения выполняются только в памяти: исходный JSON-файл VFS не изменяется.
После закрытия эмулятора созданные каталоги и копии не сохраняются.

## mkdir — создание каталога

```text
mkdir path
mkdir -p path
```

- `mkdir path` создаёт каталог, если его родитель существует.
- `mkdir -p path` создаёт недостающие родительские каталоги.
- С флагом `-p` существующий каталог не считается ошибкой.
- Поддерживаются абсолютные и относительные пути.

Примеры в окне эмулятора:

```text
mkdir /new
mkdir -p /new/a/b
```

Ошибки: путь не указан, передано несколько путей, каталог уже существует без `-p`,
родитель отсутствует или компонент пути является файлом.

## cp — копирование

```text
cp source destination
cp -r source destination
```

- `cp` копирует файл; существующий файл назначения можно перезаписать.
- `cp -r` рекурсивно копирует каталог вместе с содержимым.
- Если назначение — существующий каталог, копия создаётся в нём с именем источника.
- Копия независима от источника: последующие изменения одного дерева не меняют другое.
- Слияние существующих деревьев каталогов не поддерживается.
- `mkdir` и `cp` поддерживают `--` для завершения списка флагов.

Примеры в окне эмулятора:

```text
cp /hello.txt /new/copy.txt
cp /binary.bin /new/copy.txt
cp /hello.txt /new
cp -r /home /backup
```

Ошибки: источник отсутствует, неверное число аргументов, каталог копируется без `-r`,
объект копируется на себя, каталог копируется внутрь себя или поверх файла.
Нельзя копировать корень VFS. Ошибки отображаются в окне эмулятора и записываются в журнал.

## Запуск и проверка

Требуется Python 3.10+ с Tkinter. Команды запуска выполняются в терминале ОС из корня проекта:

```text
python src/main.py --vfs examples/vfs.json --log logs/demo.csv
python -m unittest discover -s tests -v
```

После запуска вводите примеры `mkdir` и `cp` в окне эмулятора.
Для автоматической демонстрации предусмотрен `examples/startup.txt`:
он содержит обычный и рекурсивный режимы, перезапись файла и примеры ошибок новых команд.

Проверочные сценарии Windows:

- `scripts/test_stage5_minimal.bat`
- `scripts/test_stage5_multiple.bat`
- `scripts/test_stage5_deep.bat`

Сценарии используют копии образцов VFS в папке `logs`.
Важно: демонстрационный скрипт в конце вызывает служебный `vfs-init`, который очищает
указанный JSON-файл. Поэтому для демонстрации безопаснее использовать подготовленные BAT-файлы.
