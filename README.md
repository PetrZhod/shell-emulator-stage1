# Эмулятор оболочки — этап 3

Ветка содержит GUI REPL, конфигурацию, CSV и JSON VFS. Python 3.10+ с Tkinter.
Сторонние библиотеки для программы и unittest не требуются.

## Запуск из корня проекта в терминале ОС

```text
python src/main.py --vfs examples/vfs.json --log logs/demo.csv
python -m unittest discover -s tests -v
```

Можно использовать `run.bat` или `sh run.sh`, передавая те же параметры.
Для Visual Studio: запускаемый файл `src/main.py`, рабочая папка — корень проекта.
`--script PATH` задаёт стартовый скрипт, без него ввод интерактивный.
Все параметры при запуске видны в консоли и GUI. Заголовок содержит имя VFS из JSON.
Приглашение `localhost:~#`. Парсер разделяет ввод по пробелам, без кавычек и конвейеров.

## Конфигурация и журнал

По умолчанию VFS — `examples/vfs.json`, журнал — `logs/commands.csv`, скрипт не задан.
Относительные пути считаются от рабочей папки; пути запуска с пробелами заключаются в кавычки.
CSV дополняется и содержит только `command,arguments,username,error`.
Аргументы — JSON-массив; имя пользователя берётся из ОС. Ошибки чтения/записи сообщаются.
Неподходящий существующий CSV не перезаписывается; лог не может совпадать с VFS или скриптом.
Скрипт — UTF-8/UTF-8 BOM, `#` начинает комментарий. Видны ввод и вывод.
Ошибки команд содержат файл и номер строки; выполнение продолжается, пока не встретится `exit`.
При ошибке чтения скрипт не выполняется частично. `exit now` — ошибка, а не выход.

## VFS

JSON содержит `name` и `root`. Каталог: `type: directory` и словарь `children`.
Файл: `type: file` и строка base64 `data`. Образец формата — `examples/vfs.json`.
VFS загружается в память, файлы не распаковываются, обычные операции JSON не изменяют.
`vfs-init` без аргументов очищает память и физический JSON, сохраняя имя VFS.
VFS по умолчанию после очистки — пустой корневой каталог.
Повреждённый JSON, base64, неверные имена и типы узлов отклоняются до запуска GUI.

`ls [args...]`, `cd [path]` пока заглушки. `cd` с несколькими аргументами — ошибка.
`exit` без аргументов завершает работу, неизвестная команда выводит ошибку.

## Демонстрация

Запустите любой `scripts/test_stage3_minimal.bat`, `test_stage3_multiple.bat`,
`test_stage3_deep.bat`. Каждый передаёт все три параметра и использует копию JSON в `logs`.
Минимальный образец — пустой корень; многофайловый — два файла;
глубокий содержит `/home/user/docs/readme.txt` (не менее трёх уровней).
`examples/startup.txt` проверяет команды, неверные аргументы, ошибки и остановку после exit.
Важно: вручную переданный `--vfs` будет физически очищен командой `vfs-init`.

Новые коммиты оформлены как Conventional/Scoped Commits. Старая история не переписана.
Настоящее окно и BAT-сценарии нужно дополнительно проверить в Windows.
